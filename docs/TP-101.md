# TP-101 Enterprise Integration Foundation

Five Shopware 6.7 plugin skeletons, with bounded-context folders Domain, Application and Infrastructure.

## Architecture

- Domain model and ERP port do not depend on Shopware or HTTP.
- The initial ERP adapter reports unavailable until a real API is configured.
- Existing compose.yaml is managed by shopware-cli and remains unchanged.
- Existing AMQP broker is LavinMQ, compatible with RabbitMQ clients.
- No cross-plugin persistence access or circular dependencies.
- Outbox, ERP mock, inventory migrations and real monitoring are follow-up tickets.

## Setup

```bash
docker compose -f compose.yaml -f compose.tp101.yaml up -d
docker compose exec web bin/console plugin:refresh
for p in TechPartsErpConnector TechPartsInventory TechPartsOrderOrchestrator TechPartsB2BSearch TechPartsObservability; do
  docker compose exec web bin/console plugin:install --activate "$p"
done
```

## Verification

```bash
docker compose exec web bin/console plugin:list
docker compose exec web bin/console lint:container
docker compose exec web vendor/bin/phpunit custom/plugins/TechPartsErpConnector/tests/Unit/ErpHealthTest.php
```

Tests and runtime installation must still be executed in a running Shopware environment. No successful CI or deployment is claimed.
