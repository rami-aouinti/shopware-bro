# TP-105 — ERP HTTP Client & Resilience

## Scope
Symfony HttpClient adapter with bearer authentication, bounded timeout, relative-path guard, transport exception normalization and HTTP status errors.

## Configuration
Set TP_ERP_BASE_URL, TP_ERP_API_TOKEN and TP_ERP_TIMEOUT in local environment. Never commit credentials. The example file contains placeholders only.

## Behavior
- 2xx JSON object -> returned as associative array.
- Non-2xx -> ErpApiException with HTTP status.
- Network/timeout -> ErpApiException without leaking low-level message.
- Health gateway reports unavailable when the request fails.

## Not included yet
Automatic retry/backoff, circuit breaker, secret manager integration, ERP mock server and contract/integration tests. Retries belong at the asynchronous message boundary to avoid multiplying retries across layers.
