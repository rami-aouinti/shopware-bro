# TP-102 — ERP Supplier Catalog & Persistence

## Ziel
Persist supplier-specific external product references independently from Shopware product core fields.

## Domain
SupplierReference validates supplier codes and external IDs without Shopware dependencies. RegisterSupplierReferenceHandler maps a command into a DAL upsert.

## Database
`tp_supplier_catalog` has a composite business uniqueness constraint (`supplier_code`, `external_product_id`) and an optional product UUID link. No foreign key is declared yet: Shopware product versioning must be modeled correctly before enforcing referential integrity.

## Setup
```bash
docker compose exec web bin/console plugin:refresh
docker compose exec web bin/console database:migrate --all
docker compose exec web bin/console cache:clear
docker compose exec web bin/console lint:container
```

## Verification
```bash
docker compose exec web bin/console dal:validate
docker compose exec web vendor/bin/phpunit custom/plugins/TechPartsErpConnector/tests/Unit/SupplierReferenceTest.php
```

## Limitations
- No HTTP endpoint or ERP synchronization yet.
- No migration or tests have been executed against a running container in this branch.
- The deterministic UUID is derived from the business key; confirm collision and canonicalization policy before production use.
- Product association and versioning must be reviewed in integration tests before production deployment.
