# TP-104 — Import Job Monitoring

## Ziel
Track each import run with a persistent job ID, lifecycle status, counters, timestamps and a bounded error summary.

## Statusmodell
pending -> running -> succeeded | partially_failed | failed. Current tracker creates a job directly in running state. State transition enforcement and stale-running reconciliation are follow-up work.

## Local validation
```bash
docker compose exec web bin/console plugin:refresh
docker compose exec web bin/console database:migrate --all
docker compose exec web bin/console lint:container
docker compose exec web bin/console dal:validate
```

## Production notes
- Error summaries must be truncated and scrubbed of credentials/PII before storage.
- Retention/purge policy and administration UI are not included.
- Monitoring counters are job-level; Prometheus metrics and correlation IDs will be introduced with observability work.
- No runtime tests have been executed from this change.
